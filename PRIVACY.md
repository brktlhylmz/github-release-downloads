# Privacy Policy — GitHub Release Downloads

**Last Updated:** October 26, 2026

**GitHub Release Downloads** does **not** collect, transmit, store, or share any personal data, browsing history, analytics, or telemetry on any external server.

## Data Handled Locally on Your Device

1. **GitHub API Cache & Delta Snapshots:**
   - Release and asset download counts fetched from `https://api.github.com` are cached locally in your browser's extension storage (`chrome.storage.local` / `browser.storage.local`) solely to reduce redundant network requests and display download count changes since your previous visit.
2. **Optional Personal Access Token (PAT):**
   - If you choose to provide a GitHub Personal Access Token in the extension settings popup, it is stored exclusively in your local browser storage (`storage.local`) on your device and is sent only in the `Authorization` header directly from your browser to `https://api.github.com`.
3. **No Third-Party Services:**
   - The extension contains zero analytics, zero tracking scripts, and zero third-party network requests. All network communication occurs directly between your browser and `https://api.github.com`.
